# CTF Run Records

Create one folder per event, for example `2026-10-09-fortid/`.

Each run should record:

- event, team, timezone, start/end time;
- AI mode and exact model/tool versions;
- challenge attempts by category;
- points, minutes spent, and outcome;
- observed evidence versus model inference;
- first useful observation and blocking point;
- network/remote dependency status;
- lessons and one concrete change for the next run.

Use the same fields for no-AI and AI-assisted runs so the comparison is meaningful.
