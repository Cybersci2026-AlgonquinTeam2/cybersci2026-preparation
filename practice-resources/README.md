# Team practice resources

Start with the [offline field guide](field-guide/README.md) for domain decision trees, audio and image analysis, worked drills and flashcards.

This folder is the team entry point to the existing curriculum. Linked modules remain the source of truth; avoid maintaining duplicate copies.

## Start here

1. Read the [method card and practice suite](../curriculum/practice-suite.md).
2. Pick one weak skill from the [checklist](../curriculum/checklist.md).
3. Attempt an authorized lab independently, recording observations before looking at hints.
4. Review a solution only after a serious attempt, then repeat from a clean state without it.
5. Write a short explanation and repeat on another day. Record practice evidence in [runs](../runs/README.md).
