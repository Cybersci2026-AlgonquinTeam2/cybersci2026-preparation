# CyberSci offline field guide

Use the [detailed chapters](chapters/README.md) for decision trees, terminology, worked examples, troubleshooting, and recall exercises. Each flowchart also has a text path for offline Markdown readers.

Download this folder before disconnecting. Use it during the event only if the briefing permits prepared references, including AI-authored notes. The repository records a no-AI instruction for the event. Prompt injection here is a paper exercise.

1. Start with [triage and playbooks](playbooks.md).
2. For media clues, open the [audio and image walkthrough](media.md).
3. Use [worked drills](walkthroughs.md) and [flashcards](flashcards.tsv) for recall.
4. Prepare a VM using the [Kali toolkit](https://github.com/Cybersci2026-AlgonquinTeam2/kali-toolkit) (team access).

Scope follows the [published CyberSci preparation areas](https://cybersci.ca/students/), with audio, image, and prompt injection added as supplemental practice. The organizer has not confirmed those as event categories. Web vulnerability and binary exploitation topics are covered here through code review, mitigations and non-exploit analysis.
