# Competition-Day Runbook

This is a draft until competition rules and venue constraints are verified.

## Before leaving

- [ ] Laptop-only model and tools tested with network disconnected.
- [ ] Offline notes/RAG index built and hash recorded.
- [ ] Tool binaries, wordlists, interpreters, and writeups available locally.
- [ ] VM/container snapshots created and restore procedure tested.
- [ ] Chargers, adapters, spare storage, and paper notes packed.
- [ ] Team roles and handoff format agreed.
- [ ] AI policy and allowed network behavior confirmed.

## During the event

- [ ] Record challenge scope before interacting with a target.
- [ ] Keep a timestamped hypothesis and evidence log.
- [ ] Separate model suggestion from human-verified observation.
- [ ] Require approval before any exploit or submission action.
- [ ] Record solve time, points, category, and failure reason.
- [ ] Preserve artifacts needed for a later writeup.

## Recovery

If a remote service fails, continue with laptop-local capability. If a tool behaves unexpectedly, stop the agent, preserve logs, and switch to the manual procedure. Do not improvise access outside the event's stated scope.
