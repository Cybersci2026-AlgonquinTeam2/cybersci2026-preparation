# Competition-Day Runbook

Draft until rules and venue constraints are verified. **AI tools are not allowed** (organizer reply, 2026-10-15).

## Before leaving

- [ ] Laptop boots; Kali VM starts; snapshot restore tested.
- [ ] Tools, wordlists, interpreters, cheat sheets and writeups available locally (verify offline).
- [ ] Notes search (ripgrep/fzf) works with the network disconnected.
- [ ] No local LLMs, MCP servers or agents running or installed in the competition environment.
- [ ] Rules re-read: own notes/scripts allowed? internet? what counts as "AI"?
- [ ] ID, student card, chargers, adapters, USB, paper cheat sheets, snacks, water.
- [ ] Team roles and handoff format agreed; one person owns submissions.
- [ ] Resumes printed for the afternoon interviews.

## During the event

- [ ] Triage all challenges first: rank by points / estimated minutes.
- [ ] 30-minute rule per challenge before swapping or asking.
- [ ] Record scope before interacting with a target.
- [ ] Timestamped hypothesis + evidence log.
- [ ] Verify the flag format before submitting.
- [ ] Preserve artifacts for a later writeup.

## Recovery

If a tool fails, switch to the manual procedure. Do not improvise access outside the event's stated scope.
